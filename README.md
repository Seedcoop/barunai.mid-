## 수업 활동 흐름
1. 초기 진척도(1단계) 상태에서 질문을 보내 편향/환각 징후를 찾습니다.
2. 상단 `윤리 가이드 문서` 탭에서 학생이 직접 가이드를 작성하고 `저장하기`를 누릅니다.
3. 저장된 가이드 키워드에 따라 진척도(1~3단계)가 자동 상승합니다.
4. 같은 질문을 다시 보내 응답 품질 변화를 비교합니다.

## API 사용
- 현재 화면에서는 API 설정 입력 UI를 노출하지 않습니다.
- 1단계 취약 챗봇은 로컬 시뮬레이션으로 유지됩니다.
- 2~3단계에서는 Vercel 서버리스 API(`/api/chat`)를 먼저 호출합니다.
- 서버 API 호출이 실패하면 기존 로컬 시뮬레이션으로 자동 전환됩니다.
- API Key는 브라우저 코드에 넣지 않고 Vercel 환경변수 `OPENAI_API_KEY`로만 설정합니다.

## Vercel 배포 준비
1. 이 `중등용` 폴더를 Vercel 프로젝트 루트로 배포합니다.
2. Vercel 환경변수에 `OPENAI_API_KEY`를 추가합니다.
3. 필요하면 `OPENAI_MODEL` 환경변수로 모델명을 바꿀 수 있습니다. 기본값은 `gpt-5-mini`입니다.
4. 배포 후 0단계 코드 `SDCP05`로 접속해 2~3단계 응답이 API로 생성되는지 확인합니다.
